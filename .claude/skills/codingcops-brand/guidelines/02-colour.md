## 2. Colour

| Token | Hex | Usage |
|---|---|---|
| `emerald` | `#01c16c` | Brand guide: Emerald. The ONE action colour — primary button fills, active states, highlight cards. Prussian-blue text on it (8.6:1); never white text (2.4:1). |
| `full-spectrum-blue` | `#0360e3` | Brand guide: Full Spectrum Blue. Full-bleed section bands, feature cards, links and the focus ring. White text on it (5.6:1). Prussian-blue text on it only at 24px+ (3.7:1). |
| `logo-blue` | `#004cf8` | The blue inside the logo files (mark and wordmark). Reference only — use full-spectrum-blue for UI. |
| `prussian-blue` | `#030027` | Brand guide: Prussian Blue. All text on light grounds (18.8:1 on platinum), the 2–3px outline on every card, button and input, and the dark section band. On it: white (20.3:1), emerald (8.6:1) or vibrant-coral (6.3:1). |
| `platinum` | `#f2f7f7` | Brand guide: Platinum. Page background and quiet section breaks. |
| `vibrant-coral` | `#ee6352` | Brand guide: Vibrant Coral. Warm decorative card fills, tags and highlights. Prussian-blue text on it (6.3:1); white only at 24px+ (3.2:1). Never a CTA fill. |
| `white` | `#ffffff` | Card, input, modal and nav surfaces; text on full-spectrum-blue and prussian-blue. |
| `slate` | `#575c6e` | System addition. Muted helper text and captions on platinum (6.1:1) and white (6.6:1). |
| `placeholder` | `#6e7385` | System addition. Input placeholder text on white (4.7:1). |
| `mist-border` | `#c5cad3` | System addition. Disabled borders only (1.7:1 on white — never a meaningful border or text). |
| `emerald-wash` | `#e3f8ee` | System addition, tint of emerald. Banner strip and soft section washes. Prussian-blue text on it. |
| `blue-wash` | `#e8effc` | System addition, tint of full-spectrum-blue. Alternate pale section band. Prussian-blue text on it. |
| `newsprint` | `#d9d9d4` | Social only: the torn-paper strip behind hiring and announcement headlines. Prussian-blue text on it (14.9:1). |
