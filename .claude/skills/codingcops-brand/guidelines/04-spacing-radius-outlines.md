## 4. Spacing, radius and outlines

| Token | Value | Usage |
|---|---|---|
| `space-4` | 4px | Icon-to-label nudges. |
| `space-8` | 8px | Nav inner padding; tight gaps. |
| `space-12` | 12px | Element gap, input vertical padding. |
| `space-16` | 16px | Element gap, input horizontal padding. |
| `space-18` | 18px | Button and link-pill vertical padding. |
| `space-20` | 20px | Compact card padding. |
| `space-24` | 24px | Card padding, nav left inset. |
| `space-28` | 28px | Primary button horizontal padding. |
| `space-40` | 40px | Large card padding; headline-to-content gap. |
| `space-48` | 48px | Large grid gaps. |
| `space-64` | 64px | Section band vertical padding (min). |
| `space-80` | 80px | Section band vertical padding (max), gap between sections. |
| `space-128` | 128px | Hero top padding under the floating nav. |
| `radius-nav` | 8px | Floating nav bar and inputs — the smallest radius allowed. |
| `radius-small` | 16px | Small elements, modals, icon tiles. |
| `radius-card` | 32px | Cards and frames. |
| `radius-card-lg` | 64px | Large hero and feature cards. |
| `radius-pill` | 99px | Every interactive pill: buttons, tags, link pills. |
| `radius-blob` | 1000px | Discs and organic shapes, echoing the round monogram. |
| `stroke` | 1.5px | Default prussian-blue outline on buttons, pills, inputs, nav. |
| `stroke-bold` | 2px | Cards, discs and the focus state. |
